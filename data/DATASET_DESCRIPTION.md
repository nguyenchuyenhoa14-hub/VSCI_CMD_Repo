# Dataset Description — VSD-CMD Near-Field TSV Metrology

## Overview

The dataset consists of FDTD-simulated near-field Cylindrical Modal Decomposition (CMD)
data for truncated-cone **air-filled (bare etched)** Through-Silicon Via (TSV) structures embedded in a
silicon wafer with a SiO₂ liner. The vias model the unfilled trench geometry produced by the Bosch DRIE process, prior to any Cu metallization. Simulations were performed using the Lumerical FDTD solver.

**Dataset source:** Identical to the dataset used in Chen et al. (2025),
"Singular value decomposition of near-field electromagnetic data for compressing and
accelerating deep neural networks in the prediction of geometric parameters for through
silicon via array", *Computer Physics Communications*.

## Variable Names and Shapes

### Primary arrays (both files)

| Key | Shape | Dtype | Description |
|-----|-------|-------|-------------|
| `cmd` | `(N, 100, 32, 16)` | float32 | Near-field CMD tensor |
| `labels` | `(N, 3)` | float32 | Geometric parameters |

### CMD tensor dimensions

```
cmd[sample, wavelength, mode_component, radial_ring]
```

- **Axis 0 — sample:** N = 1629 (train) or 139 (val)
- **Axis 1 — wavelength:** 100 wavelengths, λ ∈ [380, 700] nm at equal spacing
- **Axis 2 — mode component:** 16 real + 8 imaginary parts (first 8 modes real, next 8 imaginary)
- **Axis 3 — radial ring:** 16 rings, r ∈ [90, 330] nm

### Labels columns

| Column | Parameter | Unit | Range |
|--------|-----------|------|-------|
| `labels[:, 0]` | TCD (Top Critical Dimension) | nm | [270, 330] |
| `labels[:, 1]` | BCD (Bottom Critical Dimension) | nm | [200, 270] |
| `labels[:, 2]` | Depth | nm | [2700, 3300] |

## Physics LUT: tsv_physics_lut_multimode.npz

Generated by `src/generate_multimode_lut.py`. Contains the multi-mode FDM eigensystem solutions.

| Key | Shape | Description |
|-----|-------|-------------|
| `tcd_grid` | (13,) | TCD values [nm] for which LUT is pre-computed |
| `wavelengths` | (100,) | Wavelength grid [nm] |
| `r` | (Nr,) | Radial coordinate grid [nm] |
| `beta_m0` .. `beta_m4` | (13, 100) | Complex propagation constants for modes m=0..4 |
| `profile_m0` .. `profile_m4` | (13, 100, Nr) | Radial mode profiles Ψ_m(r) |

## Simulation Parameters

| Parameter | Value |
|-----------|-------|
| Solver | Lumerical FDTD |
| Via interior | **Air (bare etched, unfilled trench)** — no Cu fill |
| Liner | SiO₂ |
| Substrate | Silicon (Si) |
| SiO₂ liner thickness | 20 nm |
| Bottom interface | Air/SiO₂ Fresnel boundary |
| Yee-grid pitch | 1.64 nm |
| Source | Normally incident plane wave |
| Wavelength range | 380–700 nm |
